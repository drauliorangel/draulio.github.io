Automação de ETL e Integrações

Exemplo de script em Python utilizado para automações de rotinas e requisições a APIs em pipelines de dados.

import requests
import logging

def process_pipeline_data(endpoint_url):
    try:
        response = requests.get(endpoint_url, timeout=30)
        response.raise_for_status()
        data = response.json()
        logging.info(f"Sucesso ao extrair {len(data)} registros.")
        return data
    except Exception as e:
        logging.error(f"Erro no processo de ingestão: {e}")
        raise

Processamento Distribuído com PySpark / Databricks

Exemplo de leitura otimizada e transformações em ambientes de Big Data.

from pyspark.sql import SparkSession
from pyspark.sql.functions import col, sum, current_timestamp

spark = SparkSession.builder.appName("OptimizacaoPipeline").getOrCreate()

df = spark.read.parquet("s3://data-lake-prod/raw/eventos/")
df_tratado = df.filter(col("status") == "ACTIVE") \
               .withColumn("processado_em", current_timestamp())

df_tratado.write.mode("append").format("delta").save("s3://data-lake-prod/curated/eventos/")

Window Functions e Otimização de Consultas (BigQuery / Postgres)

Consulta avançada para particionamento e análise de métricas ao longo do tempo.

SELECT 
    cliente_id,
    data_transacao,
    valor_transacao,
    SUM(valor_transacao) OVER(
        PARTITION BY cliente_id 
        ORDER BY data_transacao 
        ROWS BETWEEN 30 PRECEDING AND CURRENT ROW
    ) AS acumulado_movel_30d
FROM 
    faturamento_clientes
WHERE 
    data_transacao >= CURRENT_DATE - INTERVAL '90' DAY;
